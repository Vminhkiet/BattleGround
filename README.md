# 3D Multiplayer Battle Royale Prototype
## Overview
This project is a 3D multiplayer battle royale prototype built with Unity.

The goal was to explore real-time multiplayer systems, character abilities, and core gameplay loops in an online environment.
## Demo
- Video: [https://youtu.be/2dwtUHTZnqs](https://youtu.be/2dwtUHTZnqs)
## Features
- Multiplayer gameplay (basic synchronization of player actions)
- Character system with multiple heroes and unique abilities
- Combat system with player interaction
- Match flow: hero selection, gameplay, death, return to selection
- Basic battle royale mechanics (shrinking zone)
## Technical Highlights
- Designed and implemented a custom hex-based map system
- Built a map editor tool to create, save, and load game maps
- Handled integration of hex-based terrain with non-hex objects (e.g. buildings)
- Developed data structures for map persistence and reconstruction
